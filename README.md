# TaskFlow

## Descripción del proyecto
TaskFlow es un sistema de gestión de tareas por consola desarrollado para NovaTech.

## Cómo ejecutarlo
1. Clonar el repositorio.
2. Ejecutar `dotnet run` en la consola.

## Tecnologías usadas
